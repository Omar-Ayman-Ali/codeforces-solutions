# M. 3N + 1

- **Problem Link:** [https://codeforces.com/group/tTJnpKpFzH/contest/645756/problem/M](https://codeforces.com/group/tTJnpKpFzH/contest/645756/problem/M)
- **Time Limit:** 2 seconds
- **Memory Limit:** 64 megabytes

## Description

Consider the following algorithm to generate a sequence of numbers.

Start with an integer *n*. If *n* is even, divide by 2. If *n* is odd, multiply by 3 and add 1. Repeat this process with the new value of *n*, terminating when *n* = 1. For example, the following sequence of numbers will be generated for *n* = 22:

22 11 34 17 52 26 13 40 20 10 5 16 8 4 2 1

Given *n*, print the generated sequence.

## Input

The first line of input consists of a single integer *T* (1 ≤ *T* ≤ 100), the number of test cases. Followed by *T* lines, each line consists of a single integer *n* (1 ≤ *n* ≤ 104).

## Output

For each test case, print the sequence generated by the integer *n*.

## Examples

### Example 1
**Input:**
```
2
22
64
```

**Output:**
```
22 11 34 17 52 26 13 40 20 10 5 16 8 4 2 1 
64 32 16 8 4 2 1
```

## Solution

See [`solution.cpp`](./solution.cpp)

```cpp
#include <iostream>

using namespace std;

#define int long long
signed main()
{
    int t, n;
    cin >> t;

    for (int i = 0; i < t; i++)
    {
        cin >> n;
        cout << n << ' ';
        while (n != 1)
        {
            if (n % 2 == 0)
                n/= 2;
            else
                n = n *3 +1;

            cout << n << ' ';
            }
            cout << endl;
    }
}
```
