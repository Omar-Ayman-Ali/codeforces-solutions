# 📚 C++ Primer & Practice Problem Solutions

This folder contains competitive programming practice problems, C++ Primer exercises, and the Assiut University Training Sheet solutions.

---

## 📁 Folder Organization

- **`assuit sheet/`**:
  - `Sheet #1 (Data type - Conditions)`: Basic input/output, conditional logic, arithmetic operations.
  - `Sheet #2 (Loops)`: While, for, nested loops, prime detection, GCD, histograms, pyramids.
  - `Contest #1`: Practice contest problem sets.
- **`Others/`**: Additional practice problems.
- **Root Files**: Top-level C++ practice solutions (`.cpp`) and helper headers.
